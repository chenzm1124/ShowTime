1. **会员体系**（PRD FR-701~FR-714）
   - 新用户终身 1 次免费试用
   - 每日 2 次广告解锁

2. **精修规则**（PRD FR-309）
   - 每组最佳1人物+1景观，共2张精修
   - 人物照用美图云修人像模板
   - 景观照用美图云修景观模板

3. **额度管理**（PRD FR-205）
   - 实时额度校验
   - 任务创建时扣减
   - 反作弊机制

## 快速开始

### 1. 安装依赖

```bash
cd travel-photo-miniprogram
npm install
```

### 2. 微信开发者工具打开

- 打开微信开发者工具
- 导入项目：选择 `travel-photo-miniprogram` 目录
- AppID：选择"测试号"或填入自己的AppID
- 编译运行

### 3. 切换Mock/真实模式

在 `src/stores/task.ts` 中：

```typescript
// Mock模式（默认，无后端可运行）
const useMock = ref(true)

// 真实模式（需要后端服务）
const useMock = ref(false)
```

## 当前模式说明

**当前为 Mock 模式**，可独立运行：
- 不需要后端服务
- 不需要真实AI接口
- 模拟完整流程：上传→筛选→精修→文案
- 数据保存在内存，刷新页面重置

**接入真实后端需要**：
1. 部署后端FastAPI服务（见 `技术实现方案-旅行照片AI处理工具.md`）
2. 申请第三方API Key（美图云修/通义千问）
3. 修改 `useMock = false`
4. 在 `api/*.ts` 中配置正确的 `BASE_URL`

## 注意事项

1. **图片占位**：当前Mock使用 `via.placeholder.com`，实际应替换为 `uni.chooseImage` 返回的本地路径
2. **微信登录**：当前Mock自动登录，生产环境需要真实 `wx.login` + 后端 `code2session`
3. **广告SDK**：当前Mock广告流程，生产环境需要接入微信优量汇SDK
4. **微信支付**：当前Mock支付流程，生产环境需要 `wx.requestPayment` + 后端支付SDK
5. **相册保存**：需要用户授权 `scope.writePhotosAlbum`
