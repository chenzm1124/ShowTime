


检查 `node_modules` 目录：
```bash
ls node_modules/@dcloudio
```

应该看到：`uni-app`、`uni-mp-weixin` 等包。

## 常见问题排查

### Q1：npm install 失败 / 报错

**问题**：`EACCES permission denied` 或 `EAI_AGAIN registry.npmjs.org`

**解决**：
```bash
# 1. 切换国内镜像
npm config set registry https://registry.npmmirror.com

# 2. 使用淘宝cnpm（备选）
npm install -g cnpm --registry=https://registry.npmmirror.com
cnpm install
```

### Q2：npm run dev:mp-weixin 启动后无输出

**问题**：终端一直卡住，没有任何输出

**解决**：
```bash
# 删除dist目录重新构建
rm -rf dist
npm run dev:mp-weixin
```

### Q3：微信开发者工具导入后白屏

**问题**：打开后模拟器白屏或报错

**可能原因与解决**：

1. **目录选择错误**：
   - ❌ 错误：选 `travel-photo-miniprogram/` 源码目录
   - ✅ 正确：选 `travel-photo-miniprogram/dist/dev/mp-weixin/`

2. **AppID错误**：
   - 如果用个人AppID，可能未配置合法域名
   - 解决：改用"测试号"

3. **ES6转ES5失败**：
   - 在 `manifest.json` 中检查 `"es6": true`

4. **pages.json路径错误**：
   - 检查所有页面路径是否都有对应文件

### Q4：编译报错 `Module not found`

**问题**：找不到某个模块

**解决**：
```bash
# 1. 删除node_modules重装
rm -rf node_modules package-lock.json
npm install

# 2. 检查import路径
# 确保使用 @/ 别名或相对路径
```

### Q5：模拟器中图片不显示

**问题**：选择照片后预览不出来

**原因**：模拟器中没有真实照片

**解决**：
- 点击"+添加"按钮
- 在弹出选择器中选几张系统图片
- 如果没有，搜索 `uni.chooseImage` 改为相册读取模式

### Q6：广告解锁点击没反应

**问题**：点击"看视频广告"按钮没反应

**原因**：当前是Mock模式，会弹出"模拟广告"提示

**解决**：在弹出框中点击"确定"完成Mock流程。

### Q7：VIP购买提示"开通成功"但状态没变

**原因**：Mock模式更新了 `userStore.userInfo`，但没有刷新首页显示

**解决**：手动从VIP页面返回首页，或重新进入"我的"页面。

## 🔧 高级调试技巧

### 1. 开启Console日志

`src/api/request.ts` 已包含详细日志，Console会显示：
```
[userStore] loginByWechat
[taskStore] createAndProcess
```

### 2. 修改后自动刷新

如果 `dev:mp-weixin` 正常运行：
- 修改 `.vue` 文件 → 微信开发者工具自动刷新
- 修改 `.ts` 文件 → 同样自动刷新
- 如未自动刷新，按 `Ctrl+B` 手动重编译

### 3. 切换Mock/真实模式

打开 `src/stores/task.ts` 第18行：

```typescript
const useMock = ref(true)   // Mock模式（默认）
// const useMock = ref(false)  // 真实后端模式
```

### 4. 查看Pinia状态

调试器 → `AppData` 标签 → 搜索 `pinia`

或代码中使用：
```typescript
const taskStore = useTaskStore()
console.log('当前任务:', taskStore.currentTaskId)
console.log('处理状态:', taskStore.taskStatus)
```

### 5. 调整Mock处理速度

打开 `src/utils/mock.ts`，修改 `simulateProcessing` 中的duration：
```typescript
{ stage: 'screening', duration: 3000, ... }  // 默认3秒
{ stage: 'screening', duration: 500, ... }   // 改为0.5秒快速演示
```
